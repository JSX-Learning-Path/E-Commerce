# E-Commerce Website - Similar to Amazon/Ebay

## Основни Функционалности:

.Регистрация на потребител.
.Качване на продукт/ти по категория.
.Търсачка за пордукти.
.Преглед на детайли за продукт.
.Добавяне на продукти в количка.
.Плащане онлайн.
.История на поръчките.
.Оценка на продукт/ти.
.Административен Панел.

## Основни страници

-Начална страница.
-Страница с количка.
-Страница с вход/регистрация.
-История на поръчките.
-Страница с детайли за продукт.
-Страница със Профил на потребителя.
-Страница със категория продукти.

## Технологии и библиотеки

-Front-end.: React .js + React routed Dom.
-UI:React Icons , Tailwind.
-Database: Firebase.
-Payments: Stripe/Paypal.
